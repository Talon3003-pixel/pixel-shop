# Studio Shot

Лёгкий настольный редактор изображений на Electron. Это самостоятельный проект, а не копия Adobe Photoshop.

## Запуск

1. Установи Node.js LTS.
2. В папке проекта выполни `npm install`.
3. Запусти приложение командой `npm start`.

## Сборка установщика Windows

Выполни `npm run dist`. Команда собирает 64-битный установщик NSIS в папку `dist`. В установщике можно выбрать папку установки; также создаются ярлыки в меню «Пуск» и на рабочем столе. Для запуска готовой программы Node.js не нужен.

## Возможности

- Открытие изображений PNG, JPG, WebP, BMP и GIF, в том числе перетаскиванием в окно.
- Перемещение слоёв, рисование кистью с настройкой мягкости, ластик, размытие, пипетка, линейный градиент, фигуры и добавление текста.
- Прямоугольное и овальное выделение, лассо, умное выделение по цвету, кадрирование и работа с выделенной областью.
- Умное выделение по цвету (клавиша W): настраиваемая чувствительность, связная область с учётом диагоналей или все похожие цвета изображения. Можно брать образец со всех видимых слоёв; Shift добавляет выделение, Alt вычитает. Выделение ограничивает рисование, ластик и фильтры; выделенную область можно удалить кнопкой на панели холста.
- Слои: добавление, выбор, скрытие, переименование, перемещение, дублирование, объединение, удаление, прозрачность и режимы наложения.
- Режимы наложения слоёв: обычный, умножение, осветление, перекрытие, затемнение, замена светлым и разница.
- Меню редактирования: отмена/повтор, копирование/вырезание/вставка, выделить всё и инверсия выделения.
- Меню изображения: поворот, отражение и кадрирование по выделению.
- Фильтры и настройка яркости, контраста и насыщенности; выделение ограничивает коррекции.
- Масштаб, панорамирование холста, горячие клавиши и меню приложения.
- Экспорт результата в PNG или JPG.
- Сохранение проекта в `.pshort` (слои, параметры наложения и выделение) и повторное открытие через меню, перетаскивание или двойной щелчок по файлу после установки приложения.
- При выходе с несохранёнными изменениями приложение предлагает сохранить проект, выйти без сохранения или отменить выход.
- Стартовая заставка с иллюстрацией, предоставленной пользователем, и подписью Fediann Yaroslav.
- Безрамочное окно с собственной панелью заголовка и кнопками сворачивания, разворачивания и закрытия.

Pixel Shot — самостоятельный 2D-редактор; это не копия Adobe Photoshop. Функции, требующие отдельного сложного движка или 3D-среды, например RAW-разработка, интеллектуальная ретушь, маски слоёв и 3D, пока не поддерживаются.

Изменения остаются в памяти приложения, пока ты не сохранишь проект `.pshort` или не экспортируешь изображение.
